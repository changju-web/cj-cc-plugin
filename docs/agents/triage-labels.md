# Triage Labels

各 skill 以五个规范 triage 角色说话。本文件把这些角色映射到本仓库工单跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签           | 含义                       |
| -------------------------- | -------------------- | -------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此工单       |
| `needs-info`               | `needs-info`         | 等待报告者补充信息         |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现               |
| `wontfix`                  | `wontfix`            | 不予处理                   |

当 skill 提到某个角色（如 "apply the AFK-ready triage label"）时，使用表中对应的标签字符串。

如需改用自有词汇，编辑右列即可。
