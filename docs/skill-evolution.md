# Skill 市场自进化机制

市场 skill 通过「双层进化环」持续进化：快环在消费项目内当天生效，慢环跨项目蒸馏回市场。信号是一等公民——在生成现场就地捕获，不做会话考古，无自动化。

## 双层环总览

```text
【快环 · 消费项目内当天生效】
生成会话出现显式信号（纠偏 / 主动要求 / 要求重生成）
  → 改产物 + 提炼规则回写项目约定记忆文件
  → 追加 docs/codegen-ledger.md 一条（原话证据）

【慢环 · 市场跨项目蒸馏】
skill-evolution:inspect（纯手动触发）
  → 读 references/consumers.md 注册表内各项目 ledger 未处理条目
  → 归因分层（api-spec / UI 生成 / 装配接缝 / 非生成）
  → 同规则点复现 ≥2 才升格市场行动项（四分类：冲突改 / 缺失增 / 冗余删 / 样本进 examples）
  → skill-evolution/<日期> 在途分支改 skill + commit（不 push）
  → 人工审合 merge + bump 涉事插件版本
```

## 约定记忆文件（快环载体）

| 文件 | 覆盖层 | 机制 |
| --- | --- | --- |
| `docs/api-spec.md` | model / api 生成（api-spec 插件） | 探测 + 询问产出；人工可编辑；下次以文件为准；删除触发重新探测 |
| `docs/ui-codegen.md` | UI 生成（ep-comp / wd-comp） | 同款机制；一份文件内分「共通 / PC (ep-comp) / 小程序 (wd-comp)」三节 |

约定文件只写**提炼后的规则语句**（一行一事），用户原话只进台账。

## 生成信号台账（慢环证据源）

消费项目 `docs/codegen-ledger.md`，进 git、纯追加、原文不可改写：

```text
- [YYYY-MM-DD] <plugin>:<skill> | <纠偏|要求|重生成> | <用户原话摘录> | <当时的处理> | <涉及产物路径>
```

行尾处理标记由巡检追加：`→ 已蒸馏 YYYY-MM-DD <plugin>@<ver>`（幂等，防重复蒸馏）或 `→ 留观 YYYY-MM-DD`（单条疑似通用，再现即凑满门槛）。

## 捕获约定（给生成会话中的 agent）

- 只记**本会话内**的显式信号：纠偏（指出不对 + 给改法）、主动要求（期望效果，非纠错）、要求重生成；闲聊与推测不入账
- 主动要求类**双写**：约定记忆文件（提炼规则）+ 台账（原话）各一条；纠偏类至少记台账
- 捕获是收尾动作，不阻塞交付

## 蒸馏与审合

- 巡检 = `skill-evolution:inspect`，**纯手动**触发；信号识别、门槛、纪律与禁区见插件内 `references/`
- 在途进化分支最多一个；merge、push、bump 只属于人
- 项目个性信号不进市场：巡检报告给出"建议写入该项目约定记忆文件"的条目，人工回写
- 巡检对消费项目的唯一写动作是台账行尾打标
- 元层不豁免：skill-evolution 自身也在可进化范围内

## 版本纪律

插件缓存按版本安装——市场改动 merge 时必须 bump 涉事插件版本，否则消费端拿到的还是旧版。
